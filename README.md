# MARQUE – USTP Event Attendance Monitoring System

## 📌 Overview

**MARQUE** is a web-based **Event Attendance Monitoring System** developed for the **University of Science and Technology of Southern Philippines (USTP)**. It is designed to efficiently track, manage, and report attendance for university events using a centralized and reliable platform.

The system minimizes manual attendance errors, improves data accuracy, and provides real-time monitoring for administrators and event organizers.

---

## 🚀 Features

* 🔐 Role-based user access (Administrator, Organizer, Staff, Participant)
* 📅 Event creation and management
* 📊 Real-time attendance monitoring
* 📷 QR Code-based attendance recording
* ✍️ Manual attendance marking (optional)
* 📄 Attendance reports and export (PDF / Excel)
* 🔎 Attendance summary and statistics
* 🔒 Secure authentication and data handling

---

## 👥 User Roles

### Administrator

* Manage users and roles
* Create, edit, and delete events
* View and export attendance reports
* Configure system settings

### Event Organizer

* Create and manage assigned events
* Monitor attendance in real time

### Staff / Attendance Manager

* Record attendance via QR scanning or manual marking
* Verify participant attendance

### Participant (Student)

* View event details
* Register for events
* Check attendance status

## 🔑 Getting Started

### 1. Access the System

Open your web browser and navigate to the MARQUE system URL provided by USTP.

### 2. Login

* Enter your **username** and **password**
* Click **Login**

> ⚠️ Invalid credentials will prompt an error message.

### 3. Logout

Click your profile icon and select **Logout**.

---

## 📋 Event Management

### Create an Event

1. Navigate to **Events > Create Event**
2. Fill in event details (name, date, time, venue, description)
3. Click **Save**

### Edit / Delete an Event

* Select an existing event
* Choose **Edit** or **Delete**

> ⚠️ Deleted events cannot be recovered.

---

## ✅ Attendance Monitoring

### QR Code Attendance

1. Open the event attendance page
2. Activate the QR scanner
3. Scan the participant’s QR code
4. Attendance is recorded automatically

### Manual Attendance

1. Select the event
2. Search for the participant
3. Click **Mark Present**
